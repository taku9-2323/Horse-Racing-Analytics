# 22 — 結果取得に失敗しても後続レースを継続する

**What to build:** 過去注目レースの結果一括取得で、レース固有または一時的な失敗は対象レースだけに記録し、後続レースの取得を継続する。

**Blocked by:** 21 — 過去注目レースのJRA結果を一括取得する

**Status:** complete

- [x] 個別結果ページの403は当該レースを失敗として後続取得を継続する
- [x] robots.txtの一時的な取得失敗は当該レースを失敗として後続取得を継続する
- [x] 404、500系、解析・保存失敗は既存どおりレース単位で処理する
- [x] 429とrobots.txtによる明示的な取得禁止では安全のため一括取得を停止する
- [x] 失敗コードと利用者向け理由をレース単位で保持する
- [x] API回帰テスト、全テスト、型検査、ビルドが成功する

**Out of scope:** レート制限後の自動再開、無人での自動再試行。
