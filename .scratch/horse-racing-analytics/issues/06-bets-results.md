# 06 — 実購入と結果を記録する

**What to build:** 利用者が単勝・複勝の実購入と裁量購入を登録し、公式結果、払戻、返還から実収支を確認できるようにする。

**Blocked by:** 04 — 複数時点の予測を固定する

**Status:** complete

- [x] 実在候補のない初版では実購入を候補外裁量として記録し、任意の候補内ラベルを拒否する
- [x] 購入額が正の100円単位に制約される
- [x] 着順と100円当たり公式払戻を取り込める
- [x] 取消・除外の購入額が同額返還として精算される
- [x] 購入額、払戻額、返還額、損益、回収率が一致する
- [x] 同一結果の再取込はno-opとし、競合結果と同着は理由付き訂正で監査履歴を残す
