# 18 — 開催週のJRAレースを一括取得・更新する

**What to build:** 個人利用者が一度の明示操作で、Asia/Tokyoにおける当日を含む月曜から日曜までのJRA開催情報、レース、出走馬、単勝・複勝オッズを取得し、取得できたレースについて同じオッズ時点のルール判定まで準備できるようにする。週前半などで未公開の情報は失敗や「注目馬なし」にせず、取得できた段階までを保存する。

**Blocked by:** 17 — 市場基準とルール判定を実運用画面で比較する

**Status:** complete — 2026-09-05

## 取得境界

- 起動は利用者による「開催週のレースを取得／更新」の明示操作だけとし、アプリ起動時の自動取得、定期実行、無人巡回は行わない。
- 対象週はAsia/Tokyoで月曜00:00から日曜23:59までとし、土日固定ではなく、JRA公式の開催日程に掲載された祝日開催や開催変更も対象にする。
- 開催日発見の入口は対象週に含まれる年の `https://www.jra.go.jp/keiba/calendarYYYY/index.html`、日別番組表は `https://www.jra.go.jp/keiba/calendarYYYY/YYYY/M/MMDD.html` の固定形だけを許可する。入口ページから辿るリンクは、同一ホスト、対象週内、日別番組表の固定形へ一致するものだけに限定する。
- 日別番組表は予定情報として扱い、正式なRace登録はADR 0003どおり、検証済み出馬表と検証済みオッズが揃った時点だけで行う。
- 出馬表、オッズ、ルール判定には既存の取得・検証・固定契約を再利用し、新しい取得経路で検証を緩めない。
- 取得は直列とし、HTTP要求間隔を1秒以上空ける。15分キャッシュと7日間のHTML証跡保持、応答監査を維持する。
- 公式日程に存在するが出馬表またはオッズが未公開の状態は正常な待ち状態とする。HTTP 403・429、robots拒否、許可外リダイレクト、想定外Content-Type・応答サイズ・HTML構造、利用条件不明ではバッチ全体を停止する。
- JRA公式ページ以外、ログインページ、投票ページ、任意URL、ページ内の無制限なリンク巡回は対象外とする。CSV取込を恒久的なフォールバックとして維持する。

## 状態契約

各開催日・競馬場・レース枠について、少なくとも次の状態を区別する。

- `schedule_only`: 開催・番組情報のみ取得済み
- `entries_waiting`: 出走情報待ち
- `odds_waiting`: 出走馬取得済み、オッズ待ち
- `judgement_waiting`: 正式レース・オッズ取得済み、ルール判定待ち
- `ready`: 同じオッズ時点のルール判定まで準備済み
- `stopped`: 取得停止理由あり

バッチ実行には対象週、開始・終了時刻、実行状態、対象件数、取得済み件数、待ち件数、失敗件数、停止理由、最後に処理した対象を保存する。同じ対象週の再実行は既存の取得版を上書きせず、新しい観測または冪等な再利用として扱う。同時に開始できるバッチは1件だけとする。

実装ではレース枠を実行単位で版管理し、開催変更で最新日程から外れたレースを最新表示へ混ぜず、過去実行の証跡は保持する。同一HTML・同一ルール版の再取得では、既存の出馬表、オッズ時点、固定判定を再利用する。

## 受入条件

- [x] `POST /api/acquisition/jra/meeting-weeks/current/runs` 相当のHTTP操作で、対象週の一括取得を1回だけ開始でき、重複開始は競合として拒否される
- [x] `GET /api/acquisition/jra/meeting-weeks/current` 相当のHTTP APIで、対象週、開催日、競馬場、レース枠、各段階、最終更新時刻、バッチ進捗、停止理由を再読込後も確認できる
- [x] JRA公式カレンダーから、対象週内の通常土日、祝日開催、開催変更を固定URL契約の範囲だけで発見できる
- [x] 週前半に番組表だけ取得できる場合、取得済みのレース枠を保存し、出走情報待ちとして返す
- [x] 出馬表が公開済みでオッズ未公開の場合はオッズ待ち、両方が揃った場合は既存契約で正式Raceとオッズスナップショットを登録する
- [x] 正式Raceとオッズが揃った対象は、選択中のルール版を同じオッズ観測時点へ適用し、レース前の固定判定として保存する
- [x] 取得時点ですでに発走後でオッズ更新時刻がない対象は、受付時刻を確定オッズの観測時刻として判定し、事後判定・公式評価対象外として保存する
- [x] 一部取得後に停止条件へ達した場合、取得済みレースと監査記録を残し、未取得件数、停止した対象、停止理由を返す
- [x] 再試行は未取得・待ち・失敗対象を再評価し、既存の取得版、固定済み判定、結果を破壊または重複させない
- [x] 取得中の件数進捗、完了、一部待ち、停止、CSVフォールバックをブラウザから確認できる
- [x] 架空のカレンダー・日別番組表・出馬表・オッズfixtureで、通常土日、祝日、週前半の未公開、一部停止、再試行を通すHTTP APIテストとUI受入テストが成功する
- [x] ADR 0002を、利用者が選んだ対象週に限定した固定形リンク発見を許容する内容へ更新し、無人巡回禁止と停止優先を維持する
