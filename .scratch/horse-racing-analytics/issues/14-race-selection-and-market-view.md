# 14 — 登録済みレースを選択して市場分析と固定予測履歴を見る

**What to build:** 利用者が登録済みレースの一覧から対象を選び、CSVを再取込せずに最新の市場分析、オッズ時点、固定予測履歴を一画面で確認できるようにする。JRAのレースカードとオッズを正式登録した直後も、登録したレースをそのまま表示する。

**Blocked by:** 12 — JRA公開ページからオッズを取得する

**Status:** complete

- [x] 分析可能な登録済みレースを開催日・発走時刻順で取得でき、データ取得元にかかわらず同じ一覧に表示される
- [x] 一覧からレースを選択すると、出走馬、最新の単勝市場基準、複勝損益分岐率レンジ、オッズ時点、固定予測履歴が表示される
- [x] JRAオッズの正式登録に成功した直後、そのレースが選択状態になり市場分析まで表示される
- [x] ページを再読込しても登録済みレースを選び直して同じ分析内容を確認でき、CSVの再取込を必要としない
- [x] 登録レースがない状態、オッズ未登録、取得失敗を区別し、利用者が次に行う操作を画面に表示する
- [x] 市場基準を独立予測や利益候補として表示せず、独立予測モデルがない場合はその旨を明示する
- [x] レース一覧・詳細取得のHTTP APIテストと、「JRA正式登録→選択→市場予測表示」のUI受入テストが成功する
