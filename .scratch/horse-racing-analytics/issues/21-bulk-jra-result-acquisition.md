# 21 — 過去注目レースのJRA結果を一括取得する

**What to build:** 過去レース画面に表示中の4開催週から結果未取得の注目レースを抽出し、保存済みレース情報からJRA公開結果ページを特定して一括取得する。

**Blocked by:** 20 — 過去レースの注目馬と着順を横断して見る

**Status:** complete

- [x] 表示中4開催週の結果未取得注目レースだけを一括取得対象にする
- [x] 保存済みのJRAレース識別情報から許可された公開結果ページを自動特定し、利用者のURL入力を不要にする
- [x] 利用者の明示操作で直列・低頻度に取得し、対象数、処理済み数、成功数、未取得数、失敗数を返す
- [x] 一部失敗でも成功済み結果を保存・表示し、失敗レースと理由を残す
- [x] 再実行は未取得・失敗対象だけを処理し、取得済み結果を破壊しない
- [x] 403・429等では停止し、既存の個別URL入力とCSV取込を代替導線として案内する
- [x] 結果訂正の確認は既存レース詳細の個別再取得から行い、旧版と差分を保持する
- [x] API・UI受入テスト、型検査、ビルド、実ブラウザ確認が成功する

**Out of scope:** 取得済み全結果の毎回再取得、無人定期実行、結果を使った期待値・回収率評価。
