# 20 — 過去レースの注目馬と着順を横断して見る

**Blocked by:** 19 — 開催週の一覧から注目レースを絞り込む

**Status:** complete

- [x] レースと馬の組み合わせを1行へ集約し、事前・事後の注目判定フラグ、最新有効結果、結果未取得、訂正有無を返す
- [x] 開催週、開催日、発走時刻の降順、同一レース内は馬番順で返し、前後ページの有無を示す
- [x] 主要ナビに「過去レース」を追加し、開催週見出しと注目馬1頭1行の一覧を表示する
- [x] 表示中4開催週に対し、開催日、競馬場、1着、2〜3着、4着以下、取消・除外・競走中止、結果未取得、事前・事後判定で絞り込める
- [x] 行から既存の固定判定レース詳細へ進み、選択馬と注目理由を強調する

- [x] API・UI受入テスト、型検査、ビルド、PC・スマートフォン実ブラウザ確認が成功する
