# 04 — 複数時点の予測を固定する

**Blocked by:** 03 — CSV取込を安全に再実行する

**Status:** ready-for-agent

- [ ] 固定済み予測を直接編集できない
- [ ] 訂正は理由付きで旧版を無効化し新版を作る
