# 17 — 市場基準とルール判定を実運用画面で比較する

**What to build:** 利用者が登録済みレースを選び、同じ予測時点における市場注目順位と固定済みルール判定を一画面で比較し、判定根拠、欠損、固定状態を確認できるようにする。

**Blocked by:** 16 — 説明可能なルールベース判定を生成・固定する

**Status:** complete

- [x] 登録済みレース画面で比較対象のオッズ時点とルール版を選択できる
- [x] 各馬について市場順位、市場シェア、ルール判定、簡潔な理由、データ欠損、固定状態を同じ行で確認できる
- [x] 市場基準とルール判定が異なる場合も一方を正解・推奨とせず、両方の根拠を個別に表示する
- [x] 未固定、固定済み、無効化済み、発走後作成を区別し、公式な事前判定に含まれる版を明示する
- [x] 画面再読込や結果・払戻の登録後も、固定済み判定の入力値、判定、理由が変化しない
- [x] オッズ未登録、判定未生成、ルール版不一致、必要データ欠損を区別し、次に必要な操作を表示する
- [x] 市場基準、ルール判定、独立予測を文言と型で区別し、期待値や購入候補を表示しない
- [x] 通常、判定不能、固定後の結果登録、不一致状態を通すHTTP APIテストとUI受入テストが成功する
