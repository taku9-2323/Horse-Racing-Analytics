# 16 — 説明可能なルールベース判定を生成・固定する

**What to build:** 利用者が事前に版として固定した決定的ルールを、予測時点で利用可能な市場・レース・出走馬情報へ適用し、各馬の「注目」「見送り」「判定不能」と理由を生成して固定できるようにする。判定は観察対象を絞るためのもので、独立確率、期待値、購入候補を生成しない。

**Blocked by:** 15 — 市場基準から注目順位を表示する

**Status:** complete

- [x] 初期ルール版が、利用可能な項目、演算子、閾値、優先順位、欠損時の扱い、判定語彙を変更不能な版として保持される
- [x] 初期ルールで利用できる項目を、オッズ水準、市場順位、保存済み時点間のオッズ変化、相対馬番、競馬場、芝・ダート、距離、馬場状態、頭数、年齢、性別、負担重量の文脈情報に限定する
- [x] 負担重量を単独の有利・不利として扱わず、複勝損益分岐率を予測確率として利用せず、分析タグの一致だけで利益優位性を主張しない
- [x] 判定実行時点以前に観測された特徴だけを使用し、後続スナップショット、最終人気、結果、払戻が混入した場合は拒否される
- [x] 各馬について「注目」「見送り」「判定不能」のいずれかと、適用ルール版、入力時点、成立条件、不成立条件、欠損理由が保存される
- [x] 固定済み判定は直接編集されず、変更は理由付き無効化と新版作成で行われ、発走後の新版は公式な事前判定から除外される
- [x] 画面がルール判定を市場順位と区別し、独自勝率、期待値、購入推奨、利益保証として表示しない
- [x] 注目・見送り・判定不能、時点リーク拒否、固定後不変性、理由付き新版を検証するHTTP APIテストとUI受入テストが成功する
