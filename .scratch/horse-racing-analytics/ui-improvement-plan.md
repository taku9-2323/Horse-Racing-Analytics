# UI改善計画（具体チケットへ置換済み）

**Status:** 2026-09-05の利用者壁打ちにより、広すぎる本計画は単独実装せず、チケット18「開催週のJRAレースを一括取得・更新する」とチケット19「開催週の一覧から注目レースを絞り込む」へ置き換えた。

**What to improve:** 機能実装と分離して、情報設計、操作フィードバック、レスポンシブ表示、アクセシビリティをまとめて見直す。

**Timing:** チケット04の利用者レビュー後に優先度と範囲を確定し、機能チケットに混ぜず実施する。

## 検討項目

- システム状態、CSV取込、分析、予測固定を迷わない画面階層に整理する
- 取込成功、冪等再取込、競合、入力エラーの状態を明確に表示する
- ワイドな分析表をモバイルで比較しやすい表示へ改善する
- 用語の説明、数値の単位、市場基準と予測の区別を視覚的に強化する
- キーボード操作、フォーカス、コントラスト、スクリーンリーダーの受入確認を追加する
- 主要画面の視覚回帰チェックを定義する

## 完了条件の候補

- 利用者レビューで優先する操作上の問題が特定されている
- デスクトップとモバイルの主要フローが実ブラウザで確認できる
- 既存の市場基準・損益分岐率・候補なしの表現が保持される
