# Issue tracker convention

The public source repository and active issue tracker are <https://github.com/taku9-2323/Horse-Racing-Analytics>. Check its open and closed issues before creating or changing an issue so work is not duplicated.

Use GitHub Issues for work that needs to be prioritized, assigned, discussed, or tracked across sessions. Keep detailed product specifications and local research under `.scratch/<effort>/`; link the GitHub issue from those documents when a corresponding issue exists. Local Markdown issue drafts are reference material and are not a second source of status.

Local work items that have not been moved to GitHub must include YAML front matter with a stable `id`, `title`, and one `triage` value from `docs/agents/triage-labels.md`.

The current effort is `.scratch/horse-racing-analytics/`.
