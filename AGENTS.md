# Project instructions

This project is a local-first JRA horse-racing analytics prototype.

## Delivery model

- Work in small, end-to-end vertical slices described in `DEVELOPMENT_PLAN.md`.
- Keep work in progress to one implementation ticket at a time.
- Preserve a working, demoable product after each completed ticket.
- Test user-visible behavior through the local HTTP API seam; add a focused UI acceptance test for critical flows.
- Do not claim that market odds or unvalidated analysis tags provide a profitable edge.

## Agent skills

- Use `docs/agents/issue-tracker.md` to locate specifications and work items.
- Use `docs/agents/triage-labels.md` for local work-item status labels.
- Use `docs/agents/domain.md` to locate domain documentation and ADRs.
- Use `CONTEXT.md` for the domain glossary and product boundary.
